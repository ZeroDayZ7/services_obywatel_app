# DBeaver Workspace Backup

Restore instructions for restoring `workspace6.7z`:

1. **Close DBeaver** completely before proceeding.
2. **Extract** `workspace6.7z` into the DBeaver data folder:
   - **Windows:** `%APPDATA%\DBeaverData\`
   - **Linux:** `~/.local/share/DBeaverData/`
   - **macOS:** `~/Library/DBeaverData/`
3. **Overwrite** the existing `workspace6` folder if prompted.
4. **Download DBeaver** (if not installed): [dbeaver.io/download](https://dbeaver.io/download/)
5. **Launch DBeaver** — all database connections, scripts, and settings will be restored.
